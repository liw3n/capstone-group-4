Read first. This build keeps everything in memory — refreshing the page wipes all your changes and restores the seed data. That is expected behaviour, not a bug. Finish a module before refreshing, and use a refresh deliberately to get back to a clean slate.

Before you start

  • Run npm install once, then npm run dev, and open localhost:3000.
  • The app is pinned to a fixed "today" of 26 Aug 2026. That is why tasks read 710 days overdue and never drift — treat those numbers as stable expected values.
  • CRM workflows use prototype role selection, in-memory data, and simulated AI. The separate PULSE chat integration is outside this runbook.
  • Use a desktop-width window (1280px or wider) unless a case says otherwise.
  • Keep the browser console open. A clean console is part of the final pass.
